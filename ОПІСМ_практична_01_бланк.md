### A.3. Запит до служби доменних імен

*Windows: `Resolve-DnsName opensuse.org`*

**Команда (перше виконання):**

```
Resolve-DnsName opensuse.org
```

**Вивід:**

```
PS C:\Users\User> Resolve-DnsName opensuse.org

Name                                           Type   TTL   Section    IPAddress
----                                           ----   ---   -------    ---------
opensuse.org                                   AAAA   2677  Answer     2a07:de40:b27e:1204::10
opensuse.org                                   A      2677  Answer     195.135.223.50
```

**Команда (повторне виконання через 5–7 хвилин):**

```
Resolve-DnsName opensuse.org
```

**Вивід:**

```
Name                                           Type   TTL   Section    IPAddress
----                                           ----   ---   -------    ---------
opensuse.org                                   AAAA   2391  Answer     2a07:de40:b27e:1204::10
opensuse.org                                   A      2391  Answer     195.135.223.50
```

**Зафіксовані значення:**

| Параметр | Перше виконання | Повторне виконання |
|---|---|---|
| Час виконання (год:хв) |19:04|19:09|
| IP-адреса |IPv6: 2a07:de40:b27e:1204::10
195.135.223.50 | IPv6: 2a07:de40:b27e:1204::10 IPv4: 195.135.223.50 |
| Значення TTL |IPv6: 2677 IPv4: 2677| IPv6: 2391 IPv4: 2391|

> Якщо друге значення TTL виявилося більшим за перше — це нормально: кеш резолвера встиг оновитися. Зафіксуйте як є.
